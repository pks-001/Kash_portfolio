# Prakash Kumar — Portfolio

A modern, premium portfolio website built with pure **HTML**, **CSS**, and **JavaScript**.

## 🌐 Live Preview

🔗 [https://pks-001.github.io/Kash_portfolio/](https://pks-001.github.io/Kash_portfolio/)

## ✨ Features

- 🎨 Premium monochrome grey/white design with glassmorphism
- ⚡ Animated particle background on hero section
- ✍️ Typing animation with rotating taglines
- 📊 Scroll-reveal animations across all sections
- 📱 Fully responsive — works on mobile, tablet, desktop
- 🧭 Smooth scroll navigation with active link highlighting
- 📬 Contact form (Formspree integration)
- 🔝 Back-to-top button
- 🎯 SEO optimized with meta tags and Open Graph

## 🚀 Deployment (GitHub Pages)

```bash
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/pks-001/Kash_portfolio.git
git push -u origin main
```

Then go to **Settings → Pages → Source: main branch** and your site will be live!

## 🛠 Tech Stack

- HTML5 (semantic)
- CSS3 (custom properties, flexbox, grid, animations)
- Vanilla JavaScript (no frameworks)
- [Lucide Icons](https://lucide.dev/)
